
# Pydantic Student Model

## Overview
This project demonstrates data validation using **Pydantic**.

## Features
- Validate student data
- Convert compatible data types
- Use Python's `BaseModel`

## Sample Data
```python
data = {
    "age": "23",
    "name": "Ali",
    "phone": "03343545"
}
```

## Output
```text
Ali
23
03343545
```

## Installation
```bash
pip install pydantic
```
